# Oxford 3000 영어 단어 학습 웹앱 개발 기획서

## 1. 프로젝트 개요

Oxford 3000 필수 영단어를 영어 단어, 한국어 뜻, 활용 문장 3개와 함께 학습하는 개인용 웹앱을 만든다.

목표는 기능을 많이 넣는 것이 아니라 **"Unit 단위로 10개씩 학습하고, 모르는 단어는 외울 때까지 다음 Unit에 계속 따라오게 하는"** 학습 흐름 하나를 빠르고 편하게 만드는 것이다. 로그인, 서버, 데이터베이스 없이 브라우저에서 바로 쓴다.

## 2. 핵심 학습 흐름

모든 기능은 아래 흐름을 위해 존재한다. 이 흐름에 기여하지 않는 기능은 넣지 않는다.

1. 앱을 열면 Unit 목록이 보이고, 상단의 **이어서 학습** 버튼으로 다음 미완료 Unit을 바로 시작한다.
2. Unit 학습 = **이번 Unit 새 단어 10개 + 이전 Unit에서 넘어온 Keep 단어 n개**.
3. 카드마다 **알아요 / Keep** 중 하나를 누르면 다음 단어로 넘어간다.
4. Keep 단어는 '알아요'를 받을 때까지 이후 모든 Unit에 계속 등장한다.
5. 모든 카드를 판정하면 Unit이 **학습 완료**로 표시된다.
6. 완료된 Unit을 다시 누르면 **복습(테스트) 모드**로 열린다.

하루 학습량은 Unit 1개를 권장하지만 제한하지는 않는다.

## 3. MVP 핵심 기능

### 3.1 단어 데이터

- Oxford 3000 목록 기반. 단어당 필드: 영어 원형, 품사, CEFR 등급(A1~B2), 한국어 뜻(1~3개), 예문 3개와 각 한국어 번역.
- 예문은 일상회화 중심으로, 3개가 서로 다른 상황·용법을 다루도록 한다.
- 데이터는 사전에 생성·검수한 정적 JSON 하나로 관리한다. 학습 중 AI API 호출은 없다.
- 같은 단어가 여러 품사를 가지면 하나의 항목으로 묶고 품사를 함께 표기한다.
- JSON 배열 순서가 곧 학습 순서다(A1 → B2, 등급 안에서는 알파벳순). Unit 번호는 `순번 ÷ 10`으로 계산하므로 데이터에 Unit 필드를 따로 두지 않는다. 약 300개 Unit이 된다.

> 실제 개발에서 가장 큰 작업은 앱이 아니라 **약 9,000개 예문의 생성과 검수**다. 등급별(A1 → B2)로 나눠 준비하고, 준비된 등급부터 앱에 반영한다.

### 3.2 Unit 구성과 Keep

**Unit 시작 시 구성**

- 이번 Unit의 새 단어 10개를 먼저, 현재 Keep 상태인 단어 전부를 그 뒤에 배치한다.
- Unit을 시작하는 순간 카드 목록을 저장해 둔다. 중간에 앱을 닫아도 같은 구성과 같은 위치에서 이어진다.

**Keep 규칙**

- 이번 Unit 새 단어에 Keep을 누르면 **다음 Unit부터** 등장한다(이번 Unit 안에서는 반복하지 않음).
- 넘어온 Keep 단어에 알아요를 누르면 Keep에서 빠진다. 다시 Keep을 누르면 다음 Unit에도 또 나온다.
- Keep 단어 수에는 상한을 두지 않는다. 쌓이는 것 자체가 "아직 못 외운 단어가 많다"는 신호이기 때문이다. 실제로 부담스러워지면 상한(예: 20개)을 추가한다.

**단어 상태**

| 상태 | 의미 |
|---|---|
| 미학습 | 아직 학습하지 않은 Unit의 단어 |
| Keep | 마지막 판정이 Keep. 이후 Unit에 계속 등장 |
| 알아요 | 마지막 판정이 알아요 |

상태는 단어별로 하나만 존재한다. 학습 모드든 복습 모드든 마지막 판정이 그 단어의 상태가 된다.

### 3.3 학습 모드 (처음 학습하는 Unit)

외우는 것이 목적이므로 정보를 바로 보여준다.

- **카드:** 영어 단어, 품사, CEFR 등급, 한국어 뜻, 예문 3개. Keep으로 넘어온 단어에는 "Keep" 표시.
- **예문 번역:** 기본으로 숨기고, 문장을 탭하면 해당 번역만 보인다. "번역 항상 보기" 설정 하나를 둔다.
- **발음:** 단어와 예문을 브라우저 내장 Web Speech API로 읽어준다.
- **판정:** 알아요 / Keep. 누르면 저장 후 다음 카드로 이동. 이전 버튼으로 돌아가 판정을 바꿀 수 있다.
- **진행 표시:** 상단에 `7 / 13 (새 단어 10 + Keep 3)` 형태.
- **완료 화면:** 알아요 / Keep 개수와 "다음 Unit으로 넘어갈 Keep 단어" 목록을 보여준다.

### 3.4 복습(테스트) 모드 (완료된 Unit)

기억했는지 확인하는 것이 목적이므로 뜻을 가린다.

- 대상: 해당 Unit의 새 단어 10개(그때 같이 나왔던 Keep 단어는 제외).
- **앞면:** 영어 단어 + 발음 버튼만 보인다. 사용자는 뜻을 떠올린다.
- **펼치기:** 탭(또는 Space)으로 뜻과 예문을 펼친다.
- **판정:** 알아요 / Keep. 결과는 단어 상태에 그대로 반영된다. 여기서 Keep을 누르면 다음에 시작하는 Unit에 등장한다.
- **완료 화면:** 맞힌 개수(알아요 / 10)를 보여준다.
- Unit의 완료 표시는 복습 결과와 상관없이 유지된다.

### 3.5 Unit 목록 (홈 화면)

- 상단: **이어서 학습** 버튼(다음 미완료 Unit 또는 진행 중인 Unit), 현재 Keep 단어 수.
- Unit 목록: 번호, CEFR 등급, 상태(미학습 / 진행 중 / 완료), 완료 Unit은 알아요 개수(예: 8/10).
- 미완료 Unit을 누르면 학습 모드, 완료 Unit을 누르면 복습 모드.
- 순서대로 학습하는 것을 기본으로 하지만 다른 Unit을 먼저 여는 것을 막지는 않는다.

### 3.6 단어 검색

- 영어 검색(입력 즉시 필터). 결과 항목: 영어 단어, 대표 뜻, CEFR 등급, 소속 Unit, 상태.
- 항목을 누르면 단어 카드를 보여준다(판정 없이 보기만).
- "Keep 단어 전체 보기" 필터를 둔다.

### 3.7 진행률

- 홈 상단에 완료 Unit 수 / 전체 Unit 수, 알아요 단어 수 / 전체 단어 수.
- 차트나 날짜별 통계는 두지 않는다.

### 3.8 사용성 기준

기능 수보다 아래 항목을 우선해서 다듬는다.

- **바로 시작:** 앱을 열면 이어서 학습 버튼 한 번으로 학습이 시작된다.
- **키보드:** Space(펼치기, 복습 모드), ←/→(이전/다음), 1(Keep), 2(알아요), P(발음).
- **모바일:** 한 손으로 쓸 수 있도록 판정 버튼을 화면 하단에 크게 배치한다. 좌우 스와이프로 이전/다음 이동.
- **반응형:** PC는 넓은 카드 중심 레이아웃, 모바일은 단일 컬럼.
- **빠른 반응:** 데이터는 처음 한 번 로드하고 이후 모든 조작은 즉시 반영된다.

### 3.9 저장 데이터 (localStorage)

| 키 | 내용 |
|---|---|
| 단어 상태 | 단어별 `keep` / `known` (없으면 미학습) |
| Unit 기록 | Unit별 완료 여부, 시작 시 저장한 카드 목록, 현재 위치 |
| 설정 | 번역 항상 보기 등 |

## 4. 부가 기능 (MVP 이후, 필요할 때만)

실제로 써보고 필요하다고 느낄 때만 추가한다.

| 기능 | 이유 | 구현 |
|---|---|---|
| 학습 기록 백업/복원 | localStorage는 브라우저 데이터 삭제 시 사라지고 기기 간 이동이 안 된다 | JSON 파일 내보내기/가져오기 버튼 2개 |
| PWA 설치·오프라인 | 휴대폰 홈 화면에서 앱처럼 실행 | Vite PWA Plugin |
| Keep 상한 | Keep 단어가 너무 쌓여 Unit 하나가 부담스러워질 때 | 오래된 Keep부터 최대 N개만 포함 |

**제외한 기능:** 즐겨찾기(Keep으로 대체), 별도 암기 테스트 화면(복습 모드로 대체), 학습 통계 차트(진행률로 충분), 날짜 기반 간격 반복(Keep 순환으로 대체), 외부 TTS.

## 6. 개발 순서

1. **데이터 구조 확정 + A1 데이터 준비.** 소량으로 먼저 앱을 만들 수 있게 한다.
2. **Unit 구성 + 학습 모드 + Keep 순환 + 저장/이어서 학습.** 이 단계만으로 핵심 흐름이 완성된다.
3. **복습 모드, 홈 Unit 목록, 진행률.**
4. **검색, 키보드/스와이프, 반응형 다듬기.**
5. **나머지 등급(A2~B2) 데이터 추가.**
6. 실사용 후 필요하면 4장의 부가 기능을 추가한다.

## 7. 성공 기준

- 앱을 열고 버튼 한 번으로 오늘 학습할 Unit(새 단어 10개 + Keep 단어)을 시작할 수 있다.
- Keep 처리한 단어는 알아요를 받을 때까지 빠짐없이 이후 Unit에 등장한다.
- 완료한 Unit은 다시 누르는 것만으로 복습 테스트를 할 수 있다.
- 중간에 앱을 닫아도 같은 Unit, 같은 카드에서 이어서 학습할 수 있다.
- 약 300개 Unit 전체를 학습 상태 손실 없이 끝까지 진행할 수 있다.
