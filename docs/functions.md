# Oxford 3000 영어 단어 학습 웹앱 개발 기획서

## 1. 프로젝트 개요

본 프로젝트는 Oxford 3000 필수 영단어를 기반으로 영어 단어와 한국어 뜻, 활용 문장 3개를 함께 학습할 수 있는 개인용 웹앱을 개발하는 것을 목표로 한다.

상업적 서비스 운영이나 사용자 확보보다는 **실제 영어 학습에 필요한 기능을 간결하고 효율적으로 제공하는 것**을 우선한다. 따라서 초기 개발에서는 회원가입, 서버 운영, 복잡한 사용자 관리 기능을 제외하고, 별도의 로그인 없이 브라우저에서 즉시 학습할 수 있는 구조를 채택한다.

개발 기능은 학습에 반드시 필요한 **MVP 핵심 기능**과 학습 편의성 및 효율을 높이기 위한 **부가 기능**으로 구분한다.

## 2. MVP 핵심 기능

### 2.1 단어 데이터 및 학습 콘텐츠

Oxford 3000 공식 단어 목록을 기반으로 학습 데이터를 구성한다. 각 단어는 영어 원형, 품사, CEFR 난이도, 한국어 뜻, 활용 문장 3개, 각 문장의 한국어 번역을 포함한다.

활용 문장은 단어의 실제 사용법을 이해할 수 있도록 일상회화 중심으로 구성하며, 문장마다 서로 다른 상황이나 표현을 다루도록 한다.

단어 데이터는 초기에는 JSON 파일로 관리하여 별도의 데이터베이스 서버 없이 웹앱에서 직접 불러올 수 있도록 한다. 단어와 예문 데이터는 사전에 생성하고 검수하며, 학습 중 실시간 AI API 호출은 사용하지 않는다.

**필요 기술:** JSON 데이터, 정적 파일 로딩, TypeScript 데이터 타입 정의

### 2.2 단어 학습 카드

웹앱의 핵심 화면은 하나의 단어를 집중적으로 학습할 수 있는 카드 형태로 구성한다.

학습 카드에는 영어 단어와 한국어 뜻을 상단에 표시하고, 하단에는 활용 문장 3개와 각 문장의 한국어 번역을 제공한다. 사용자는 이전 및 다음 버튼을 통해 단어를 순차적으로 학습할 수 있다.

영어 문장을 먼저 읽고 의미를 생각해 볼 수 있도록 한국어 번역을 개별적으로 숨기거나 표시하는 기능을 제공한다.

**필요 기술:** React 컴포넌트, React Hooks, CSS 기반 반응형 레이아웃

### 2.3 단어 목록 및 검색

전체 단어를 목록 형태로 제공하고, 영어 단어를 검색하여 원하는 학습 카드로 즉시 이동할 수 있도록 한다.

단어 목록에서는 영어 원형, 대표 한국어 뜻, CEFR 등급, 학습 상태를 확인할 수 있다.

A1, A2, B1, B2 등급별 필터를 제공하여 사용자가 자신의 수준에 맞는 단어만 선택적으로 학습할 수 있도록 한다.

**필요 기술:** JavaScript 배열 검색 및 필터링, React 상태 관리

### 2.4 학습 상태 및 즐겨찾기

사용자는 각 단어의 학습 상태를 '미학습', '학습 중', '암기 완료'로 변경할 수 있다.

별도의 즐겨찾기 기능을 제공하여 반복적으로 학습하고 싶은 단어를 저장하고, 즐겨찾기에 등록한 단어만 모아서 학습할 수 있도록 한다.

학습 상태와 즐겨찾기 정보는 브라우저에 저장하여 페이지를 새로고침하거나 브라우저를 종료하더라도 유지되도록 한다.

**필요 기술:** localStorage, Zustand 또는 React Context

### 2.5 학습 진행률 및 이어서 학습

전체 단어 수 대비 학습 완료된 단어 수를 계산하여 진행률을 표시한다.

CEFR 등급별 학습 진행률도 함께 제공하며, 사용자가 마지막으로 학습한 단어의 위치를 저장하여 다음 접속 시 이어서 학습할 수 있도록 한다.

초기에는 복잡한 통계 분석 없이 전체 학습량과 현재 진행 상태만 제공한다.

**필요 기술:** React 상태 관리, localStorage, 진행률 계산 로직

### 2.6 반응형 웹 인터페이스

PC와 모바일 환경에서 모두 편리하게 사용할 수 있도록 반응형 UI를 구현한다.

PC에서는 단어 목록과 학습 카드를 함께 확인할 수 있는 구조를 적용하고, 모바일에서는 단어 학습 카드 중심의 단일 컬럼 레이아웃을 제공한다.

별도의 모바일 앱 개발 없이 Chrome, Safari 등 일반 웹브라우저에서 동일한 학습 기능을 사용할 수 있도록 한다.

**필요 기술:** CSS Flexbox/Grid, Media Query, 모바일 터치 인터페이스

## 3. 부가 기능 및 확장 기술

### 3.1 영어 발음 재생

영어 단어와 활용 문장을 음성으로 들을 수 있는 기능을 추가한다.

초기에는 브라우저에서 제공하는 Web Speech API를 활용하여 별도의 유료 음성 합성 서비스 없이 발음을 재생한다.

향후 발음 품질이나 억양의 일관성이 중요해질 경우 외부 TTS 서비스 또는 라이선스가 확보된 발음 음원으로 교체할 수 있도록 한다.

**필요 기술:** Web Speech API, SpeechSynthesis

### 3.2 간격 반복 학습

학습한 단어를 일정한 주기로 복습할 수 있는 기능을 추가한다.

사용자가 단어를 얼마나 잘 기억하는지 직접 평가하면 해당 결과에 따라 다음 복습 시점을 계산한다.

초기에는 단순한 복습 간격 규칙을 적용하고, 필요에 따라 SM-2 등의 간격 반복 알고리즘을 도입한다.

**필요 기술:** JavaScript 날짜 계산, 복습 스케줄링 알고리즘, localStorage

### 3.3 단어 암기 테스트

영어 단어를 보여주고 한국어 뜻을 떠올리거나, 한국어 뜻을 보고 영어 단어를 기억하는 테스트 기능을 제공한다.

정답을 바로 표시하지 않고 사용자가 스스로 답을 생각한 후 정답을 확인하는 방식으로 구현한다.

테스트 결과는 학습 상태 및 복습 기능과 연계할 수 있도록 설계한다.

**필요 기술:** React 상태 관리, 문제 출제 및 정답 확인 로직

### 3.4 학습 통계

일별 학습 단어 수, 누적 학습량, 암기 완료 비율, 연속 학습 일수 등을 시각화한다.

통계 데이터는 사용자의 학습 기록을 기반으로 계산하며, 초기에는 외부 분석 서비스 없이 브라우저 내부에서 처리한다.

**필요 기술:** Recharts 또는 Chart.js, 날짜별 학습 기록 저장

### 3.5 데이터 백업 및 복원

브라우저 저장소의 데이터가 삭제되거나 다른 기기에서 학습을 이어가야 하는 상황에 대비하여 학습 기록을 JSON 파일로 내보내고 가져오는 기능을 제공한다.

이를 통해 서버나 회원가입 시스템 없이도 사용자가 자신의 학습 데이터를 직접 관리할 수 있도록 한다.

**필요 기술:** Blob API, File API, JSON 직렬화 및 역직렬화

### 3.6 PWA 지원

웹앱을 모바일 홈 화면에 설치하여 일반 앱처럼 실행할 수 있도록 PWA 기능을 추가한다.

단어 데이터와 정적 리소스를 캐싱하여 인터넷 연결이 불안정하거나 없는 환경에서도 학습할 수 있도록 한다.

**필요 기술:** Web App Manifest, Service Worker, Vite PWA Plugin

## 4. 기술 스택 및 시스템 구조

본 프로젝트는 서버 운영 부담을 최소화하기 위해 **프론트엔드 중심의 정적 웹앱 구조**를 채택한다.

| 구분 | MVP 적용 기술 | 목적 |
|---|---|---|
| 프레임워크 | React + TypeScript | 학습 화면 및 기능 구현 |
| 빌드 도구 | Vite | 개발 및 정적 빌드 |
| 스타일링 | CSS Modules 또는 일반 CSS | 반응형 UI |
| 상태 관리 | Zustand | 학습 상태 및 화면 상태 |
| 단어 데이터 | JSON | Oxford 3000 학습 콘텐츠 |
| 사용자 데이터 | localStorage | 학습 기록 영구 저장 |
| 라우팅 | React Router | 화면 및 단어 상세 경로 |
| 배포 | Vercel | 정적 웹앱 배포 |

백엔드 서버와 데이터베이스는 MVP 단계에서 사용하지 않는다. 단어 콘텐츠는 정적 JSON으로 제공하고, 사용자별 학습 정보는 브라우저에서 관리한다.

이러한 구조는 운영 비용을 최소화하고 기능 구현 및 유지보수에 집중할 수 있다는 장점이 있다. 다만 localStorage 데이터는 브라우저 환경에 종속되므로, 데이터 백업 및 복원 기능을 향후 우선적으로 추가한다.

## 5. 개발 우선순위

### 1단계: MVP 구현

가장 먼저 Oxford 3000 단어 데이터 구조를 확정하고, 한국어 뜻과 활용 문장 3개를 포함한 학습 콘텐츠를 준비한다.

이후 단어 학습 카드, 단어 목록, 검색, CEFR 필터, 학습 상태 관리, 즐겨찾기, 학습 진행률 기능을 구현한다.

이 단계가 완료되면 사용자는 웹브라우저에서 3,000개 단어를 학습하고 자신의 학습 상태를 관리할 수 있어야 한다.

### 2단계: 학습 효율 개선

기본적인 단어 학습 기능이 안정적으로 동작하면 발음 재생, 암기 테스트, 간격 반복 복습 기능을 추가한다.

이 단계에서는 새로운 콘텐츠를 늘리기보다 이미 제공되는 단어를 더 효과적으로 기억하고 활용할 수 있도록 개선하는 데 집중한다.

### 3단계: 사용 편의성 개선

학습 통계, 데이터 백업 및 복원, PWA 설치, 오프라인 학습 기능을 추가한다.

이를 통해 개인용 영어 학습 도구로서 장기간 안정적으로 사용할 수 있는 환경을 완성한다.

## 6. 개발 원칙

프로젝트의 핵심은 기능의 수를 늘리는 것이 아니라 영어 단어를 효과적으로 학습할 수 있는 경험을 제공하는 데 있다.

따라서 개발 과정에서는 다음 원칙을 유지한다.

- **학습 중심:** 영어 단어, 한국어 뜻, 활용 문장 3개를 가장 중요한 콘텐츠로 취급한다.
- **최소한의 기술 구성:** 기능 구현에 필요하지 않은 서버, 인증, 외부 API 및 데이터베이스 도입을 지양한다.
- **빠른 접근성:** 로그인이나 복잡한 설정 없이 즉시 학습을 시작할 수 있도록 한다.
- **데이터 지속성:** 학습 기록을 안정적으로 저장하고 향후 백업 및 복원이 가능하도록 설계한다.
- **점진적 확장:** MVP를 먼저 완성한 뒤 실제 사용 경험을 바탕으로 필요한 기능만 추가한다.

## 7. 최종 목표

최종적으로 본 프로젝트는 별도의 계정이나 유료 서비스 없이 웹브라우저만으로 사용할 수 있는 개인용 영어 학습 도구를 지향한다.

사용자는 Oxford 3000의 영어 단어와 한국어 뜻, 활용 문장 3개를 반복적으로 학습하면서 자신의 학습 진행 상황을 관리할 수 있다.

**MVP의 성공 기준은 3,000개 단어를 불편함 없이 학습하고, 학습한 내용을 저장하며, 언제든 이전 학습 위치에서 다시 시작할 수 있는 것이다.**

이후 발음, 복습, 테스트와 같은 기능을 추가하여 단순 단어장에서 장기적으로 활용 가능한 개인 맞춤형 영어 학습 환경으로 발전시키는 것을 목표로 한다.
